在 Jetchat 项目中，Compose 与传统 View 系统通过以下几种方式共存和交互：

## Compose 与传统 View 系统的共存和交互方式

Jetchat 项目中主要通过以下几种桥接机制实现 Compose 与传统 View 系统的共存和交互：

### 1. ComposeView 在传统 View 系统中嵌入 Compose UI

**桥接代码位置**：

- `app/src/main/res/layout/fragment_profile.xml` - 在传统 XML 布局中使用 ComposeView
- `app/src/main/java/com/example/compose/jetchat/profile/ProfileFragment.kt` - 在 Fragment 中设置 ComposeView 的内容

**代码示例**：

```xml
<!-- fragment_profile.xml 中 -->
<androidx.compose.ui.platform.ComposeView
    android:id="@+id/toolbar_compose_view"
    android:layout_width="match_parent"
    android:layout_height="wrap_content" />
```

```kotlin
// ProfileFragment.kt 中
rootView.findViewById<ComposeView>(R.id.toolbar_compose_view).apply {
    setContent {
        // Compose UI 内容
    }
}
```

### 2. AndroidViewBinding 在 Compose 中嵌入传统 View

**桥接代码位置**：

- `app/src/main/java/com/example/compose/jetchat/NavActivity.kt` - 使用 AndroidViewBinding 将传统 View 嵌入 Compose

**代码示例**：

```kotlin
// NavActivity.kt 中
JetchatDrawer(...) {
    AndroidViewBinding(ContentMainBinding::inflate)
}
```

### 3. 通过 Fragment 嵌入 Compose UI

**桥接代码位置**：

- `app/src/main/java/com/example/compose/jetchat/conversation/ConversationFragment.kt` - 整个 Fragment 返回 ComposeView

**代码示例**：

```kotlin
// ConversationFragment.kt 中
override fun onCreateView(...): View = ComposeView(inflater.context).apply {
    layoutParams = LayoutParams(MATCH_PARENT, MATCH_PARENT)
    setContent {
        // Compose UI 内容
    }
}
```

### 4. 导航系统中的混合使用

项目使用传统的 Navigation Component（基于 Fragment）进行导航，但是每个目标屏幕可以是 Compose 或传统 View。

**桥接代码位置**：

- `app/src/main/res/layout/content_main.xml` - 包含 NavHostFragment
- `app/src/main/java/com/example/compose/jetchat/NavActivity.kt` - 获取 NavController 并管理导航

## 关键桥接技术总结

1. **ComposeView**：Android View 的子类，可以在传统 View 系统中托管 Compose UI
2. **AndroidViewBinding**：允许在 Compose UI 中嵌入传统 XML 布局
3. **混合架构**：使用传统的 Fragment 导航系统，但每个 Fragment 可以选择使用 Compose 或传统 View

这种混合架构使得应用程序可以逐步迁移到 Compose，同时保持对传统 View 系统的兼容性。
