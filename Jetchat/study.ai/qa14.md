# 项目如何组织和管理资源文件？请列出关键资源文件的路径

Jetchat 项目按照标准的 Android 应用程序结构组织和管理资源文件，遵循 Jetpack Compose 应用的最佳实践。以下是项目中关键资源文件的路径和组织方式：

## 资源文件组织结构

### 图形资源

- **app/src/main/res/drawable/** - 包含应用程序的图标、矢量图形和其他图像资源
  - `ic_jetchat.xml` - 应用主图标
  - `ic_launcher_foreground.xml` - 启动器图标前景
  - `jetchat_logo.xml` - 应用标志
  - `ic_baseline_person_24.xml` - 个人资料图标

### 布局资源

- **app/src/main/res/layout/** - 包含传统的 XML 布局文件
  - `content_main.xml` - 主内容布局
  - `fragment_profile.xml` - 个人资料页面布局

### 导航资源

- **app/src/main/res/navigation/** - 包含导航图和导航组件资源
  - `mobile_navigation.xml` - 定义应用程序的导航结构

### 菜单资源

- **app/src/main/res/menu/** - 包含菜单定义
  - `activity_main_drawer.xml` - 主活动的抽屉菜单

### 值资源

- **app/src/main/res/values/** - 包含字符串、颜色、尺寸和主题定义
  - `strings.xml` - 应用程序的文本字符串
  - `colors.xml` - 颜色定义
  - `themes.xml` - 应用主题
  - `dimens.xml` - 尺寸定义

### 字体资源

- **app/src/main/res/font/** - 包含应用程序使用的字体文件
  - `montserrat_regular.ttf`、`montserrat_medium.ttf` 等 - Montserrat 字体系列
  - `karla_regular.ttf`、`karla_bold.ttf` - Karla 字体系列

### 代码中的资源管理

- **app/src/main/java/com/example/compose/jetchat/data/FakeData.kt** - 包含示例聊天数据，引用了资源 ID
- **app/src/main/java/com/example/compose/jetchat/theme/** - 包含 Jetpack Compose 主题定义
  - `Color.kt` - 颜色定义
  - `Typography.kt` - 排版样式
  - `Themes.kt` - 应用主题定义

### 其他资源目录

- **app/src/main/res/values-night/** - 夜间模式下的值资源
- **app/src/main/res/values-v23/** 和 **values-v27/** - 特定 Android 版本的资源
- **app/src/main/res/drawable-nodpi/** - 与设备 DPI 无关的图像资源
- **app/src/main/res/mipmap-xxxhdpi/** 和其他 mipmap 目录 - 不同分辨率的应用图标

## 资源管理特点

1. **资源分离** - 将界面元素与代码分离，遵循 Android 资源管理最佳实践
2. **多分辨率支持** - 通过不同的资源目录（如 drawable、mipmap-xxxhdpi 等）支持不同屏幕尺寸和密度
3. **主题和样式** - 使用 Jetpack Compose 的主题系统，在 theme 包中定义颜色、排版等样式
4. **多语言支持** - 通过 strings.xml 实现国际化
5. **Compose 与传统 XML 混合** - 项目同时包含 Compose UI 组件和传统 XML 布局

这种组织方式使得资源文件易于管理、更新和维护，并支持不同设备的适配。
